# OpenFEM

準静的 **有限要素法 (FEM)** による、電気回路パラメータ (R / L / C) 抽出ソルバー。

配線・基板パターン・伝送線路などの 3 次元形状から、静電界・定常電流界を
FEM で解いて **容量行列 C・インダクタンス行列 L・抵抗/コンダクタンス行列 R, G**
を求め、SPICE の等価回路 (サブサーキット) として書き出します。

[OpenFDTD](https://github.com/Sirokujira/OpenFDTD) と同じ構成 (C99 + CMake +
OpenMP、`mesh`/`material`/`geometry` の入力書式、`ofd.log` 相当のログ、
ポストプロセッサ分離) を踏襲した別リポジトリです。FDTD が「時間領域の
電磁界」を解くのに対し、こちらは「回路として見たときの定数」を求めます。

## 何を解くか

いずれも節点スカラー量 u (電位 φ またはベクトルポテンシャル成分 Az) に対する
準静的な弱形式

```
∫ c ∇w・∇u dV = ∫ w f dV
```

を、**構造格子** (8 節点 trilinear 6 面体要素、2x2x2 Gauss 積分で厳密) または
**非構造格子** (4 節点 1 次四面体 / 10 節点 2 次四面体要素) で離散化します。
係数 c は**対称テンソル** (非対角を含む 6 成分) として持てるので、
主軸が格子軸と一致しない異方性材料 (`anisoeps` / `anisomur`) も扱えます。

以下は構造格子を前提とした説明です。非構造格子は「非構造格子」節を参照
してください (対応する解析は C / L / R、要素は 1 次と 2 次)。

| 解析 | 方程式 / 係数 | 得られる量 |
|---|---|---|
| `C` | ∇・(ε0 εr ∇φ) = 0 | 短絡容量行列 (Maxwell 行列) [F] または [F/m] |
| `L` | ∇・(ε0 ∇φ) = 0 (真空) | L = μ0 ε0 inv(C0) : TEM 近似 (外部インダクタンスのみ) [H/m] |
| `R` | ∇・((σ + ω ε0 εr tanδ) ∇φ) = 0 | 並列コンダクタンス行列 G と R = inv(G)。導電損 + 誘電損 |
| `M` | ∇・(ν ∇Az) = −Jz | DC インダクタンス行列 [H/m]。**内部インダクタンス込み、μr 対応**。B-H 曲線があれば**非線形** |
| `F` | ∇・(∇Az/(μ0 μr)) − jωσAz + σV' = 0 | 周波数 f での直列 R(f), L(f) [Ω/m, H/m]。**表皮効果・近接効果込み** |

`M` (静磁場) はベクトルポテンシャル Az の 2 次元断面定式化です。ポート k に +I、
基準導体に −I を一様電流密度で流して解き、相互エネルギー
∫J^(j)・A^(k) dV = L_kj I_k I_j から L 行列を得ます。導体内部の電流分布を
含むので内部インダクタンスが自動的に入ります (正味電流が 0 なので純 Neumann 系は
可解。1 節点を固定して解いた解を使い、結果は定数分に依りません)。

材料に B-H 曲線 (`bh`) を与えると `M` は **非線形静磁場解析** になります。
ν = H(|B|)/|B| を Gauss 点毎に評価し、**Newton-Raphson 法**

```
R(A) = K(ν(|∇A|)) A − b = 0
J_ij = Σ_g w [ ν (∇N_i・∇N_j) + 2 (dν/dB²) (∇N_i・∇A)(∇N_j・∇A) ] detJ
```

で解きます (H(B) が単調なら J は正定値なので Jacobi-PCG が使えます)。
得られる L は与えた電流での**磁束鎖交 (割線) インダクタンス**で、電流を上げると
飽和して下がります。重ね合わせが成り立たないので単一ポート専用です。
ν の逐次代入は飽和領域で振動するため使っていません。

`bh` に軸 (`X`/`Y`/`Z`) を指定すると**直交異方性の非線形材料**になります。
この場合エネルギーが軸毎に分離するので、残差・ヤコビアンは

```
R_i  = ∫ [ H_p(B_p) ∂N_i/∂q − H_q(B_q) ∂N_i/∂p ] dV
J_ij = ∫ [ (dH_p/dB) ∂N_i/∂q ∂N_j/∂q + (dH_q/dB) ∂N_i/∂p ∂N_j/∂p ] dV
```

となり rank-1 補正項は現れません (p, q は伝送線路軸の次の 2 軸、B_p = ∂A/∂q,
B_q = −∂A/∂p)。

### ヒステリシス (Jiles-Atherton)

`ja` で Jiles-Atherton モデルを与え、`currentsweep` で電流を掃引すると
**履歴 (残留磁束・保磁力) を追う**解析になります。

```
M_an(He) = Ms (coth(He/a) − a/He),   He = H + αM
dM/dH = [ (1−c) δ_M (M_an−M)/(δk − α(M_an−M)) + c dM_an/dHe ] / [ 1 − αc dM_an/dHe ]
```

FEM の未知数は A なので **B が駆動変数**になります (逆 J-A)。
`dH/dB = 1/(μ0(1+χ))`、`dM/dB = χ/(μ0(1+χ))` を Heun 法で積分しますが、
H を `B/μ0 − M` で代数的に求めると**桁落ちで壊れる**ため (高透磁率では
B/μ0 と M がほぼ相殺し、M の相対誤差 1e-3 が H の 100% 誤差になる)、
**H も B に沿って積分**しています。

ヒステリシスでは ν = H/B が第 2 象限で負になるので行列には使えません。
行列は常に正の**微分**磁気抵抗率 dH/dB で組み (SPD なので Jacobi-PCG が使える)、
残差側だけで正確な H(B) を扱う固定点反復にしています。残留磁束・保磁力を
正しく扱うため B は符号付きで持ち、最初に磁化した向きを基準ベクトルにします
(場が回転しない問題では厳密。回転磁界は未対応)。

状態 (B, H, M, 磁化方向) は Gauss 点毎に保持し、各掃引点で収束したら確定させます。

`F` (時間調和渦電流) は複素 Az の 2 次元断面定式化です。基準導体を V'=0 に
固定してポート j を V'=1 [V/m] で励振し、各ポートの電流
I_k = ∫_k σ(V'_k − jωAz) dS から単位長あたりのアドミタンス行列 Y を作り、
Z_loop = inv(Y) から R(f) = Re Z、L(f) = Im Z/ω を得ます。導体内部の電流分布を
解くので**表皮効果・近接効果**が入ります (複素対称行列なので COCG 法で解く)。
境界条件は自然境界条件 (磁気壁) で、これは「帰路電流はモデル内の導体を流れる」
という伝送線路の前提そのものです。格子が表皮深さを刻めていない場合は警告します。

導体に `conductorsigma` を与えると、断面積から **DC 直列抵抗**
Rs = 1/(σA) [Ω/m] を求めます (帰路は基準導体が共有するものとして
Rs[k][j] = R0 + (k=j のとき Rk))。これで RLGC が揃います。

導体 (電極) 上の節点を Dirichlet 境界とし、ポート k のみを `voltage` [V]、
他の導体と基準導体 (id=0) を 0 [V] として解きます。各導体上の反作用
Σ (K φ)_i から電荷 Q_j (静電界) / 電流 I_j (電流界) を求め、
`C[k][j] = Q_j / V`、`G[k][j] = I_j / V` として行列を組み立てます。

外側境界はいずれの解析も自然境界条件 (∂u/∂n = 0) です。静電界では電気力線が
境界に平行に、静磁場では磁束線が境界に垂直になります。閉じたシールド構造では
これが厳密な条件になり、開放問題では解析領域を対象より十分広く取ってください。

線形ソルバーは対角スケーリング前処理付き共役勾配法 (実対称は Jacobi-PCG、
渦電流の複素対称系は COCG、いずれも OpenMP 並列) です。剛性行列は
CRS (27 点ステンシル) で保持します。

## 周波数掃引 (`frequencysweep`)

`frequency` は 1 点だけなので、周波数特性を出すには `.ofe` を書き換えて
回し直す必要がありました。`frequencysweep` で 1 回の実行にまとめられます。

```
frequencysweep = 1e3 1e5 1e7      # 明示列挙
frequencysweep = log 1e8 1e10 5   # 対数等分 5 点
frequencysweep = lin 1e9 5e9 3    # 線形等分 3 点
```

各点で**分散材料を展開し直して**から解き直します (εr(ω), tanδ(ω) が点ごとに
変わる)。結果は **`ofe_sweep.csv`** に 1 行 1 周波数で出ます:

```
frequency [Hz],C(1;1),G(1;1),R(1;1)
1.00000000e+08,2.64414642e-13,8.61164622e-06,1.16121816e+05
...
```

`ofe.out` / `rlc.csv` / `ofe_field.vtk` には**最後の周波数**の結果が入ります
(掃引が無い従来の挙動と同じ形にするため)。`currentsweep` (ヒステリシス) との
併用は物理的に意味がないので入力エラーにします。

**検証** (`data/sample/sweep_plate.ofe`): Lorentz 共鳴 (2 GHz) をまたぐ 5 点を
掃引し、各点を閉形式と比較します (C が 3.6 倍変化する)。加えて
**掃引の各点が個別実行と完全一致すること**を見ます — これが掃引間の状態の
漏れを直接捕まえる検査です。

実際にこの検査で不具合が 1 件出ました。異方性テンソルの埋め込み条件が
`eps6[0] <= 0` だったため 2 回目以降スキップされ、**分散材料の C が最初の
周波数で凍結**していました (`eps6_given` フラグで判定するよう修正)。

| 埋め込んだ誤り | 検出 |
|---|---|
| 埋め条件を `eps6[0] <= 0` に戻す (実際の不具合) | C +3.85% |
| 掃引ループで `material_freq()` を呼ばない | G −65.75% |
| `log` の生成を `lin` にする | 周波数が +714% |
| `currentsweep` との併用禁止を外す | 弾かれずに NG |

## 場の出力 (`fieldout = 1`)

`fieldout = 1` を書くと、解いた場を **`ofe_field.vtk`** (VTK legacy ASCII) に
出力します。ParaView / VisIt でそのまま開けます (外部ライブラリ非依存)。

| 格子 | DATASET |
|---|---|
| 構造格子 | `RECTILINEAR_GRID` |
| 非構造格子 (1 次) | `UNSTRUCTURED_GRID` (`VTK_TETRA`) |
| 非構造格子 (2 次) | `UNSTRUCTURED_GRID` (`VTK_QUADRATIC_TETRA`) |

| 解析 | 節点スカラー | 要素ベクトル |
|---|---|---|
| `C` / `L` / `R` | `phi_<mode>_port<k>` | `E_<mode>_port<k>` = −∇φ |
| `M` | `Az_M[_port<k>]` | `B_M[_port<k>]` = ∇×(Az ẑ) |
| `F` | `Az_F_re/im_port<k>` | `B_F_re/im_port<k>`、`J_F_re/im_port<k>` = σ(V′ − jωAz) |
| `A` | — | `B_A_re` = ∇×A、`J_A_re` / `J_A_im` = −σ(jωA + ∇φ) |

`A` (3 次元渦電流) が A と φ そのものを出さないのは意図的です。既定では
ゲージを固定しないので A・φ 自体は物理的な値ではなく、**B と J だけが
ゲージ不変**だからです (実測: `gauge = 0` と `gauge = 1` で B, J は 3e-10 で一致)。

要素ベクトルはセル中心での値です (構造格子は 3 重線形補間の中心微分 = 各方向
4 本の辺差分の平均で厳密、四面体は ∇λ が要素内一定なので厳密)。
`material` と `conductor` の番号も要素データとして出るので、モデルの確認に使えます。

### 検証 — 場から集中定数を作り直す

場の出力の検証は「見た目が正しい」では意味がないので、**書き出した場から
集中定数を計算し直して元の抽出値と比べます**。どちらも厳密な恒等式です:

```
∫ ½ ε |E|² dV = ½ C V²          (静電界)
∫ |J|²/(2σ) dV = ½ Re(V I*)     (渦電流)
```

| 検査 | 結果 |
|---|---|
| C を場から再計算 (構造格子) | 元の C と 2.7e-9 で一致 |
| C を場から再計算 (四面体) | 同上 |
| オーム損を場から再計算 (100 Hz、`A`) | 端子電力と 8 桁一致 |
| \|E\| の一様性 (parallel_plate) | min = max = 5000.0000000000 V/m (厳密) |

`F` (2 次元渦電流) は複素解なので、**実部と虚部の両方**が効く恒等式で検査します:

| 検査 | 恒等式 | 結果 |
|---|---|---|
| オーム損 | ∫\|J\|²/(2σ) dA = ½Re(Y) | 9 桁一致 |
| 磁気エネルギー | ω∫\|B\|²/μ0 dA = X/(R²+X²) | 8 桁一致 |
| 励振導体の電流 | ∫J dA = Y (符号つき) | 実部・虚部とも 9 桁一致 |
| 帰路導体の電流 | ちょうど符号が逆 | 10 桁一致 |

渦電流のオーム損が低周波でだけ厳密なのは、J を重心で評価しているためです
(t/δ = 0.15 で −0.0000%、0.48 で −0.0002%、1.51 で −0.015%、4.79 で −0.42%)。
これは**検査側の求積誤差**であって場の誤差ではありません。

`data/sample/field_probe_x.ofe` / `_y.ofe` は場の出力専用の検証ケースです。
直列 2 材料で E が区分一様になり、3 軸とも長さと分割数が違い、通電方向は
不等間隔にしてあります。等間隔・一様場では次の誤りがどれも**見えない**ため、
意図的にこの形にしています:

| 埋め込んだ誤り | 素朴な検査 | 現検査 |
|---|---|---|
| 勾配の分母 dx を dy に取り違え | 見逃す | mean E_x −57.14% |
| 勾配の分母 dy を dz に取り違え | 見逃す | mean E_y −33.33% |
| VTK のセル並べ替えを i/k 逆に | 見逃す | 界面の両側が入れ替わり −37.5% / +100% |
| 勾配の符号を落とす (E = +∇φ) | 見逃す (\|E\|² は符号に無感) | mean が符号反転 −200% |
| A-φ の J から ∇φ 項を落とす | — | \|J\| −99.99% |
| A-φ の重心での W_e を 1/4 → 1/2 | — | オーム損 +0.01% |
| F の J の虚部の符号を落とす | 見逃す (\|J\|² は符号に無感) | Im(I) −200% |
| F の B の虚部を実部と同じにする | 見逃す | 磁気エネルギー +100% |
| F の B を回転でなく勾配にする | 見逃す (**大きさが同じ**) | B の向きが x → y |
| F の J から V′ 項を落とす | — | オーム損がずれる |
| F の Az の中心値を 8 で割り忘れる | — | オーム損 +0.05% |

最後から 3 行目が特徴的です。∇×(Az ẑ) を −∇Az に取り違えても**ベクトルが 90°
回るだけで大きさは変わらない**ので、エネルギーの恒等式では原理的に見えません。
板が x 方向に一様なので正しい B は x 向きになる、という**向き**の検査でだけ落ちます。

## どの解析がどの材料量を読むか

材料係数の読み出しは `material_coef_pub()` (`sol/assemble.c`) に集約されています。
**指定しても読まれないキーがある**ので、対応を明示します:

| キー | `C` | `L` | `R` | `M` | `F` | `A` | `E` |
|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| `material` の εr / `anisoeps` | ✓ | – | ✓ | – | – | – | – |
| `tand` (`frequency` > 0 のとき) | – | – | ✓ | – | – | – | – |
| `debye` / `lorentz` / `drude` / `colecole` | ✓ | – | ✓ | – | – | – | – |
| `material` の σ / `tempco` | – | – | ✓ | – | – | ✓ | ✓ |
| `mur` / `anisomur` | – | – | – | ✓ | ✓ | ✓ | ✓ |
| `conductorsigma` / `conductortempco` | – | – | – | Rs | ✓ | – | – |
| `bh` / `ja` | – | – | – | ✓ | 禁止 | 到達不能 | – |

**`analysis = L` は材料を一切読みません** (真空静電界 ε0 固定)。TEM の外部
インダクタンスを求めるためのモードで、誘電体を入れたい場合は `C` を使います。

### 導電率の読み出しが 2 系統ある

これがいちばん間違えやすい点です:

| 系統 | 与えるキー | 読む解析 |
|---|---|---|
| `Material[].sigma` | `material` の 2 番目の値、`tempco` | **`R` / `A` / `E`** |
| `CondSigma[]` | `conductorsigma`、`conductortempco` | **`Rs` / `F`** |

構造格子の `F` は「`conductor` 形状で指定したセル」の導電率を使う設計なので
(`assemble_mass()`)、`material` の σ は読みません。逆に非構造格子の `A` には
`conductor` の概念が無く `electrode` タグしかないので、`conductorsigma` は
読まれません。**取り違えても値が 0 になるだけで黙って通る**ため、
解いた解析が読まないキーが指定されていると `ofe` は警告を出します:

```
*** warning : conductortempco (conductor 1) scales CondSigma, which only Rs and
              analysis F read; for R / A / E use tempco instead
```

警告は標準出力と `ofe.log` の両方に出ます (誤りではないので停止はしません)。

## 非構造格子 (四面体)

`mesh` キーで Gmsh ASCII 2.2 形式の四面体メッシュを読むと、非構造格子で
解きます。物理タグで領域と電極を指定します。

```
mesh      = coax_tet.msh
material  = 2.1 0
region    = 1 2        # 体積の物理タグ 1 -> 材料 2
electrode = 10 0       # 面の物理タグ 10 -> 基準導体
electrode = 11 1       # 面の物理タグ 11 -> ポート 1
analysis  = C L
tline     = Z          # 単位長は節点の外接直方体から取る
```

1 次四面体は要素内で勾配が一定なので要素行列は厳密積分になります。
CRS のパターンは四面体の連結から作ります (構造格子のように格納位置を
計算では求められないので二分探索を使います)。Dirichlet の扱い・反作用からの
電荷抽出・反復解法は構造格子版と共通です。

**曲面に適合できるので階段近似の誤差が消えます**。同軸線路では構造格子
(200x200 セル = 8 万節点) で C' の誤差 −2.11% だったものが、円形境界に
適合した四面体格子 (1632 節点) で **+0.18%** になります。

対応する解析は **C / L / R** です (`M` / `F` は断面 2 次元の定式化なので
構造格子専用)。検証用のメッシュは `data/sample/mkmesh.py` で生成できます
(外部のメッシュ生成器は不要)。

### 2 次要素 (10 節点四面体)

格子ファイルが Gmsh の要素型 **11** (tet10) と **9** (tri6) なら、2 次の
節点要素で解きます。指定するキーはありません — 次数は格子から決まります
(混在は弾く)。`mkmesh.py -order 2` で生成できます。

要素は**等パラメトリック**です。形状も場も同じ 2 次形状関数で表すので、
辺上の中間節点を境界形状に載せておけば境界が折れ線でなく放物線になります。
積分は Duffy 変換 + 各方向 3 点 Gauss-Legendre (27 点)。四面体の少点数則は
次数を上げると負の重みが出るうえ係数を検算しにくいので、1 次元 Gauss の積で
書ける Duffy を選びました (重みはすべて正、直線要素では厳密)。

粗い同軸 (半径 4 分割、周 12 分割) での C' の誤差:

| 要素 | 中間節点 | C' の誤差 |
|---|---|---|
| 1 次 | — | +2.99% |
| 2 次 | 辺の中点 (直線要素) | +0.61% |
| 2 次 | 円筒面に載せる (等パラメトリック) | **+0.087%** |

つまり誤差の内訳は「場の 1 次近似」と「境界の折れ線近似」がほぼ同程度で、
両方を潰して初めて 34 倍良くなります。曲がった格子で積分した体積は
円環の解析値に h^4 で収束します (周 12/24/48 分割で
−1.55e−4 / −9.77e−6 / −6.11e−7、比はどちらも 16)。頂点だけで積分すると
内接多角形の体積 −4.51e−2 になるので、等パラメトリック写像が効かなくなれば
290 倍ずれます。

制約:

- **辺要素の解析 (`E` / `A`) は 1 次格子専用**です。Whitney 形状関数が
  1 次四面体の頂点に基づいているため、2 次格子を渡すと辺上の中間節点が
  どの要素にも現れず節点ブロックが特異になります。黙って誤答を出さないよう
  弾きます。
- 電極面は 6 節点三角形で与えてください。四面体だけ 2 次で三角形が 1 次だと
  電極の中間節点が固定されず「穴だらけの電極」になります (収束はするが
  Q が合わない) ので、これも弾きます。

`analysis = P` で節点要素 (1 次 / 2 次の両方) の自己検証が走ります。
多項式の再現性

    φ(r) = a・r + (1/2) r^T B r,   φ^T K φ = ∫ (∇φ)^T C (∇φ) dV

を、要素毎の閉形式で独立に計算した右辺と比べます (機械精度)。
1 次の φ は ∇φ が要素内で一定になるので**どんな積分則でも厳密**になり、
積分則の誤りは 2 次の φ でしか捕まりません。要素の重心での勾配
(`fieldout` が書き出す値) も同じ恒等式で検証します。

変異解析で確かめた検出能力 (すべて `rlc_check.sh` で落ちる):

| 壊し方 | 落ちる検査 |
|---|---|
| 積分則を 1 点 (重心) 則にする | (c) 2 次の場 |
| 頂点の形状関数を λ_a (1 次) にする | (c) 2 次の場 |
| 中間節点の係数 4 を 2 にする | (c) 2 次の場 |

| J^-1 を転置する | (b) 1 次の場 |
| 曲がった格子の判定を常に「直線」にする | 曲がった格子の (c) が誤検出 |
| Duffy の (1−v) 因子を落とす | (c) 2 次の場 |

### 断面 2 次元の格子 (三角形) — `M` / `F`

`M` (静磁場) と `F` (時間調和渦電流) は伝送線路軸に垂直な**断面の 2 次元問題**
なので、四面体ではなく三角形で切った格子に載ります。四面体を 1 つも含まない
`.msh` を渡すと 2 次元格子として扱い、三角形が体積要素になります。

```
mesh      = plate2d.msh
material  = 1.0 0
region    = 1 2        # 三角形の物理タグ 1 -> 材料 2
electrode = 10 0       # 三角形の物理タグ 10 -> **導体断面** (基準導体)
electrode = 11 1       # 三角形の物理タグ 11 -> 導体断面 (ポート 1)
analysis  = M
tline     = X          # 面はこの軸に垂直でなければならない
```

3 次元格子と違い `electrode` は「電極面」ではなく**導体の断面**を指します
(2 次元では電極面にあたるものが無い)。すべて単位長あたりで扱うので、
`CondArea` は断面積そのもの、出力は [Ω/m] / [H/m] になります。

平行平板線路 (W=1mm, d=0.2mm, t=0.05mm) を y-z 断面で切って 1 次元厳密解と
比較した結果 (伝送線路軸は x、構造格子版は z なので面内 2 軸の取り方も検査に入る):

| 量 | 誤差 |
|---|---|
| L'dc = μ0(d + 2t/3)/W | −0.04% |
| Rs' = 2/(σWt) | −0.00% |
| R(1kHz) / L(1kHz) | −0.00% / −0.04% |
| R(10MHz) / L(10MHz) | +0.02% / −0.04% |

制約: 非線形 (`bh`) とヒステリシス (`ja`) は Gauss 点毎の状態を構造格子の
セル配列で持っているため 2 次元格子では使えません (入力エラーにします)。
2 次要素も 3 次元格子専用です。`C` / `L` / `R` / `E` / `A` / `P` は 3 次元格子が要ります。

### 面内の異方性 ν は B に掛かる (修正した不具合)

2 次元 Az 定式化のエネルギーは ∫B^T ν B/2 で、B = ∇×(Az ê_t) は

```
B_p = +∂Az/∂q,   B_q = −∂Az/∂p
```

なので、∇Az の基底に直すと**面内 2 成分が入れ替わり、非対角の符号が反転**します:

```
c_pp = ν_qq,   c_qq = ν_pp,   c_pq = −ν_pq
```

ν をそのまま ∇Az に掛けると μ_p と μ_q を取り違えます。等方性では一致するので
**等方性のケースだけでは絶対に検出できません**。実際、異方性 μ と `M` / `F` を
組み合わせた検証ケースが無かったため:

- 構造格子は `nucell` に μ_xx だけを入れて等方的に扱っており、
  μ_yy / μ_zz を指定しても黙って無視していました。
- 三角形の経路は最初テンソルをそのまま ∇Az に掛けており、平行平板線路で
  L が +138% ずれていました。

どちらも `material_coef_pub()` の mode 4 (「∇Az の基底での ν」) に集約して修正し、
両方の格子に検証ケースを置きました。

**1 次元解では面内勾配の片方しか立たない**ので、片方の格子だけでは面内テンソルの
一方の成分が一度も検査されません (実測: `c_pp` を壊す変異が回転前の格子だけでは
素通りしました)。面内で 90 度回した格子 (`plate2d_rot`) を対にしてあります。

| 埋め込んだ誤り | 検出 |
|---|---|
| mode 4 を丸ごと外す (ν を ∇Az に直接) | L −77.4% |
| `c_pp = ν_pp` (入れ替えを外す) | 回した格子で L −77.4% |
| `c_qq = ν_qq` (入れ替えを外す) | L −77.4% / +342.8% |
| `c_pq = +ν_pq` (符号を反転しない) | 回した格子で L −67.3% |
| `c_pq` を落とす | 回した格子で L −55.9% |
| 三角形の質量 1/12 → 1/9 | R −20.0%、L −36.0% |
| 三角形の非対角項の係数を半分に | 落ちる |
| `tri_grad` が面内 2 軸を取り違える | 落ちる |
| `analysis = C` を 2 次元格子で | 弾かれること |
| 2 次元格子が tline に垂直でない | 弾かれること |
| `bh` を 2 次元格子で | 弾かれること |
| 格子と材料テンソルの回転角を揃えない | 合同でなくなり落ちる |

#### 非対角成分をどう検査するか

`c_pq = −ν_pq` は最初どうやっても検査できませんでした。1 次元解では
∂Az/∂p = 0 なので非対角項が効かず、同軸 (2 次元の場) は回転対称なので
テンソルを回しても答えが変わりません (符号を反転してもビット単位で同じ結果に
なることを確認しました)。閉形式も無く、行き止まりに見えます。

抜け道は**格子を斜めに回すこと**です。`plate2d_r30.msh` は `plate2d.msh` を
面内に 30 度回しただけで**位相は同一**なので、材料テンソルも同じ 30 度回せば
元と合同な離散問題になり、答えは一致しなければなりません。

```
μ = diag(5, 1) を 30 度回す
  μ_yy = 5c² + 1s² = 4,  μ_zz = 5s² + 1c² = 2,  μ_yz = (5−1)cs = 1.7320508…
```

実測で全桁一致しました。閉形式が無くても**合同性そのものが厳密な恒等式**に
なります。非対角を落とすと −32.0%、符号を反転すると回転でなく鏡映になるので
−67.3% ずれます。

## 3 次元渦電流 (A-φ) — 辺要素

節点要素ではベクトルポテンシャル A の接線連続性を正しく課せないため、
3 次元の渦電流解析には**辺要素**が要ります。その基盤として、辺の抽出・
辺ベース CRS・Whitney (1 次 Nedelec) 要素行列を実装しています
(`sol/edge.c`、`analysis = E` で自己検証が走る)。

```
W_e     = λ_i ∇λ_j − λ_j ∇λ_i
∇×W_e   = 2 ∇λ_i × ∇λ_j                         (要素内で一定)
S_ef    = ∫ (∇×W_e)ᵀ ν (∇×W_f) dV = 4V (c_e)ᵀ ν (c_f)
T_ef    = ∫ σ W_e・W_f dV
        = σV/20 [ (1+δ_ac) g_bd − (1+δ_ad) g_bc − (1+δ_bc) g_ad + (1+δ_bd) g_ac ]
```

`∫ λ_a λ_b dV = V(1+δ_ab)/20` を使うので閉形式で厳密です。辺は全体節点番号の
小さい方から大きい方へ向きを揃え、局所の並びが逆なら符号を掛けます。

自己検証 (`data/sample/edge_test.ofe`) は閉形式で厳密に決まる量を見ます。
回転場の回転ベクトルは **a = (1,2,3)** と軸に平行でない向きにとります
(軸に平行だと ν の 1 成分しか比較に効きません):

| 検査 | 期待値 | 等方性 | 異方性 |
|---|---|---|---|
| (a) 勾配は S の零空間 | 0 | 1.6e-17 | 2.5e-17 |
| (b) 一様場の質量 uᵀTu | \|E0\|² Σ σ_e V_e | 誤差 3.0e-16 | 3.0e-16 |
| (b') 一様場は回転 0 | 0 | 2.9e-18 | 2.2e-17 |
| (c) 回転場 E = ½(a×r) の uᵀSu | Σ (aᵀν_e a) V_e | 誤差 4.0e-14 | 8.9e-15 |
| (c2) 同じ回転場の質量 uᵀTu | Σ σ_e ∫\|E\|² dV | 誤差 0.0 | 0.0 |
| (d) S と T の対称性 | 0 | 0.0 / 0.0 | 0.0 / 0.0 |

(b) (c) (c2) の場はいずれも最低次 Nedelec 空間 {a + b×r} に含まれるので補間が
厳密になり、要素行列・辺の向き・組み立てのいずれかが誤っていれば必ず落ちます。

**なぜ (c2) と異方性ケースが要るか。** (b) の一様場は Nedelec 補間が要素内で
定数になるため、どんな数値積分でも厳密に積分されてしまいます。空間変化する場
(c2) でないと質量行列の階数落ちを検出できません。同様に、等方性材料では ν の
非対角成分が恒等的に 0 なので要素行列の異方性項が一度も実行されません。
`data/sample/edge_test_aniso.ofe` は 6 成分すべてが非零な μ で同じ検証を回します。
実際に変異解析で確かめた検出能力:

| 埋め込んだ誤り | 旧検査 | 現検査 |
|---|---|---|
| ν の別成分と比較 (ν_xx ↔ ν_zz) | 見逃す (異方性では逆に誤報) | (c) が落ちる |
| ν_xx, ν_yy を 2 倍 | 見逃す | (c) 3.6e-01 |
| 非対角項の添字を入れ替え係数 2 を落とす | 見逃す | 異方性で (c) 3.4e-01, (d)S 8.0e-02 |
| 質量を 1 点 (重心) 則にする (階数 6→3) | 見逃す (3e-16 で合格) | (c2) 2.1e-03 |
| 質量項に非対称な転記ミス | 見逃す | (c2) 6.3e-01, (d)T 3.2e-01 |

### ゲージ固定 (段階 3)

回転回転行列 S の零空間は「節点関数の勾配」全体なので、非導電領域を含む系は
特異になります。**全域木 (tree-cotree) の辺で A_e = 0** と置くとこの零空間が
ちょうど消えます (勾配が全ての木辺で 0 ⟺ φ が木上で一定 ⟺ φ が一定 ⟺ 勾配が 0)。

検証: 567 節点の格子で木辺 566 本 = 節点数 − 連結成分数。勾配ベクトルの
S エネルギーはゲージ前 1.9e-17 (零空間) に対しゲージ後 1.1e-01 — 零空間が
実際に消えていることを示します。

### 前処理 (段階 4)

回転回転系の悪条件は「勾配に近い成分」が原因なので、**Hiptmair 型**の
補助空間前処理でその成分を節点空間へ移して処理します。

```
M⁻¹ r = D_e⁻¹ r + G [ N⁻¹ (Gᵀ r) ],   N = Gᵀ A G  (節点補助行列)
```

G は離散勾配 (辺 e に対し φ_hi − φ_lo)、N は節点の CRS パターンに入ります
(同じ四面体の辺の端点は同じ四面体の節点なので必ずパターン内)。節点解は
内側 PCG で近似するため前処理が反復毎に変わるので、外側は
**flexible CG** (Polak-Ribière 型 β) にしています。

検証 (A = S + 10⁻³T、残差 10⁻¹²):

| 前処理 | 反復 | 生の誤差 | **curl の誤差** |
|---|---|---|---|
| Jacobi | 494 | 1.65e-01 | 4.46e-10 |
| Hiptmair | 287 | 5.03e-04 | 2.44e-12 |

**curl の誤差** (= 磁束密度 B の誤差) はどちらも小さい — 悪条件による誤差は
勾配に近い成分に集中し、curl A には寄与しないためです。物理量は両者とも
正しく出た上で、Hiptmair は反復 1.7 倍・生の誤差 328 倍の改善になります。

### A-φ 連成 (段階 5) — `analysis = A`

未知数はベクトルポテンシャル A (辺) と電気スカラーポテンシャル φ (節点)、
電界は E = −jωA − ∇φ、J = σE です。Ampere 則と電流連続の 2 本を
Galerkin 離散化し、**2 本目を jω で割ると係数行列が複素対称**になります:

```
[ S + jωT       T G      ] [A]   [0]
[ G^T T     G^T T G/(jω) ] [φ] = [0]
```

S は回転回転行列、T は σ の辺質量行列、G は離散勾配です。(1,2) = TG、
(2,1) = (TG)ᵀ で対角ブロックも対称なので、既存の COCG がそのまま使えます。
Whitney 恒等式から GᵀTG は節点の導電行列 ∫σ∇N_a・∇N_b に一致するので、
**ω→0 で DC の導電解析に厳密に帰着**します (検証はこの極限も見ます)。

励振は電極の φ Dirichlet で、電流は電極上の反作用 Σ∫∇N_m・σ(jωA+∇φ) から
取ります。Z = inv(Y)。`awall = <面タグ>` でその面の A の接線成分を 0
(B・n = 0 の対称面 / 磁束を通さない境界) にできます。

**ゲージ**: 連成系は (A, φ) → (A + Gψ, φ − jωψ) で不変なので特異ですが、
右辺を Dirichlet の持ち上げ b = −A x_D で作る限り b は必ず値域に入るので
系は無矛盾で、COCG は解に収束します。Z はゲージ不変なので既定では固定しません。
実測 (下の検証ケース) では**固定しない方が反復が約 6 倍少なく、Z は 7 桁一致**
します。ただしその解の A・φ 自体は物理的な値ではない (A が物理解の 1000 倍、
両端 0V/1V の φ が ±60V まで振れる) ので、場そのものが要るときは `gauge = 1`
で tree-cotree ゲージを入れます (awall の辺を優先して木に入れ、境界条件と
端子電圧を壊さないようにしています)。**`gauge = 1` は、すべての電極が awall の辺
だけで連結している必要があります** — そうでないと木から決まる ψ が電極毎に別の
定数になり端子電圧がずれるので、その場合はエラーで停止します。

**検証** (`data/sample/bar_eddy.ofe`): 銅の直方体 (L=2mm, W=0.25mm, t=1mm) の
両端に電圧を与え、上下面と両端面で A_t = 0 とすると解は 1 次元になり厳密解が
出ます。

```
J_x(z) = σE0 cosh(γ(z−t/2))/cosh(γt/2),  γ = sqrt(jωμσ)
Z = γL / (2σW tanh(γt/2))     →  ω→0 で L/(σWt) (DC 抵抗)
```

| 周波数 | t/δ | R 誤差 | L 誤差 | 反復 |
|---|---|---|---|---|
| 100 Hz | 0.15 | **−0.000%** | −0.11% | 390 |
| 10 kHz | 1.51 | +0.06% | −0.13% | 403 |
| 100 kHz | 4.79 | +1.01% | −1.10% | 437 |

100 Hz の R は DC 抵抗 L/(σWt) に 7 桁一致します (連成系全体の検査)。
併せて次の 3 点も検査します (いずれも変異解析で検出能力を確認済み):

| 検査 | 落とす誤り |
|---|---|
| `gauge = 1` で Z が変わらないこと | 木の awall 優先を外すと L が −46% ずれる |
| 磁性導体 (μr = 50) の R, L | ν = (μ0μr)⁻¹ の材料参照を落とすと L が −98% |
| μr = 50, 100 kHz で表皮深さ警告が出ること | 表皮深さの計算から μr を落とすと警告が消える |

**表皮深さの診断には μr が要ります。** δ = sqrt(2/(ωμ0μr σ)) なので μ0 だけで
計算すると磁性導体で δ を √μr 倍に過大評価し、格子が粗すぎるときに警告が出ません
(異方性のときは向きが決まらないので μr の最大値 = δ の最小値を取ります)。

### 非導電領域 (空気) を含む系

空気 (σ = 0) を混ぜても**ソルバー側の変更は要りません**。理由は 2 つです:

- 右辺は Dirichlet の持ち上げ b = −A x_D なので、空気が増やす零空間
  {(Gψ_air, 0)} に対しても b は直交したままで、系は無矛盾のままです。
  実測でも反復回数は導体のみの場合と同程度 (空気層 380〜424 回、
  導体体積の 128 倍の空気箱でも 571 回、0.01 Hz でも 478 回) でした。
- 空気の**節点**は行も列も恒等的に 0 で、かつ Dirichlet 固定されます。
  空気の**辺**の対角は S_ee > 0 (回転回転) なので Jacobi 前処理は成立します。

`gauge = 1` も空気があるまま同じ Z を 7 桁で再現します (反復は約 4〜5 倍)。

**注意点が 2 つあり、どちらも格子の作り方の問題です:**

1. **A_t = 0 の面は空気側も覆うこと。** 導体側だけタグを付けると、空気部分の
   同じ面が自然境界条件になって接線 H が 0 に強制され、答えが変わります
   (実測: R +29%、Im(Z) +81%)。**ソルバーは検出できません。**
2. **外部境界を全部磁気壁にしない。** 空気を含む系で `awall` を 1 つも
   指定しないと、収束はするのに R が 9 桁ずれます。しかも **R > 0, L > 0 の
   ままなので受動性検査をすり抜けます** — 頼れるのは
   「no awall surface」警告だけなので、これを無視しないでください。

また `gauge = 1` は全電極が `awall` の辺で連結している必要があるので、
導体が空気に完全に囲まれて電極面が内部にある構成では使えません
(設計どおりエラーで停止します。既定の `gauge = 0` は問題ありません)。

**検証** (`data/sample/bar_air.ofe`): 導体棒の上に厚さ 0.5mm の空気層を載せます。
解は 1 次元のままで、空気層は界面で Robin 条件 A(t) + (g/μr)A′(t) = 0 に潰れるので
閉形式が残ります:

```
X = (cosh(γt) − 1 + (g/μr)γ sinh(γt)) / (sinh(γt) + (g/μr)γ cosh(γt))
Z = γL / (σW [sinh(γt) − X(cosh(γt) − 1)])
```

g → 0 で `bar_eddy` の 2tanh(γt/2) に**厳密に**戻ります (機械精度で確認)。
20 万要素の独立な 1 次元 FEM とも 1e-9 以内、DC のエネルギー積分とも一致します。

| 周波数 | R 誤差 | L 誤差 |
|---|---|---|
| 100 Hz | −0.000% | −0.06% |
| 10 kHz | +0.07% | −0.07% |
| 100 kHz | +1.11% | −0.67% |
| 100 Hz, μr = 50 | +0.02% | −0.11% |

**この空気層は L の半分を担っています** (g = 0 なら L = 8.378e-10、
g = 0.5mm で 1.676e-09)。変異解析での検出能力:

| 埋め込んだ誤り | bar_eddy (導体のみ) | bar_air |
|---|---|---|
| 空気要素を組み立てから外す | 見逃す | L +99.9% |
| 空気の辺を A = 0 に固定 | 見逃す | L −50.1% (R は −4% しか動かない) |
| 材料参照を要素毎でなく固定 | **見逃す** (−0.12%、許容内) | L +93.7% |

最後の行が重要です。`bar_air` は**1 つの格子に 2 つの異なる ν が同居する
唯一のケース**なので、要素毎の材料参照の誤りを捕まえられるのはここだけです。

**要素の形について。** 1 次 Nedelec 要素の誤差は「場が変化する方向の刻み」では
なく**要素の最大寸法**で決まります。上のケースは x・y に一様な解ですが、
dz を 1/40 まで細かくしても dx = 1.7mm を放置すると R が 13% ずれ、
dx = 0.42mm で 1%、0.083mm で 0.06% になりました。扁平な要素は避けてください
(ログに最大要素寸法と表皮深さの比を出します)。

## 入力ファイル (.ofe)

1 行 1 キーの `key = value ...` 形式。`#` 以降はコメント、`end` で終端。
先頭行はプログラム名とバージョン。`mesh` / `material` / `geometry` の書式は
OpenFDTD の `.ofd` と共通なので、既存モデルの記述をそのまま流用できます。

```
OpenFEM 1 0
title = microstrip line
xmesh = -4e-3 30 -1e-3 80 1e-3 30 4e-3
ymesh = 0 16 0.4e-3 2 0.435e-3 60 4e-3
zmesh = 0 1 1e-4
material = 4.4 0
geometry = 2 1 -4e-3 4e-3 0 0.4e-3 0 1e-4
conductor = 0 1 -4e-3     4e-3     0      0        0 1e-4
conductor = 1 1 -0.375e-3 0.375e-3 0.4e-3 0.435e-3 0 1e-4
analysis = C L
tline = Z
end
```

| キー | 書式 | 既定値 | 説明 |
|---|---|---|---|
| `title` | 文字列 | 空 | 表題 |
| `xmesh` / `ymesh` / `zmesh` | `x0 n1 x1 n2 x2 ...` | (構造格子で必須) | 領域境界と分割数 |
| `mesh` | `<file.msh>` | なし | 非構造格子 (Gmsh ASCII 2.2)。指定すると四面体で解く。要素型 4/2 なら 1 次、11/9 なら 2 次 (等パラメトリック)。次数は格子から決まり、混在は入力エラー |
| `region` | `<physical_tag> <material_id>` | なし | 非構造格子の体積タグ → 材料 |
| `electrode` | `<physical_tag> <conductor_id>` | なし | 非構造格子の面タグ → 電極 |
| `material` | `<epsr> <sigma>` | — | 材料。番号は 2 から順に振られる (0=真空, 1=PEC 予約)。`.ofd` の 4/5 値形式も受け付け、透磁率は無視する |
| `geometry` | `<material_id> <shape> <g0>..<g5>` | — | 材料を割り当てる形状 (セル中心で判定、後の行が優先) |
| `conductor` | `<id> <shape> <g0>..<g5>` | (必須) | 電極。`id=0` が基準導体 (グランド)、`id>=1` がポート。`id=-1` は取り消し (くり抜き)。節点で判定するので厚さ 0 の指定は「面」として扱える |
| `mur` | `<material_id> <mur>` | 1 | 比透磁率 (静磁場解析)。`material` の後に書く |
| `bh` | `<material_id> [<X\|Y\|Z>] <H> <B>` | なし | B-H 曲線の点 (複数行)。H, B とも正で単調増加、原点は書かない。軸を書くと直交異方性 (3 軸とも必要)。与えると `M` が非線形解析になる |
| `nlsolver` | `<maxiter> <tol> <damping>` | `50 1e-5 1.0` | 非線形 (B-H / ヒステリシス) 反復の設定 |
| `ja` | `<material_id> <Ms> <a> <alpha> <k> <c>` | なし | Jiles-Atherton ヒステリシスモデル。`currentsweep` と併用する |
| `currentsweep` | `<I1> <I2> ...` | なし | 電流掃引 (履歴に沿って順に解く)。`ja` が必要 |
| `jasub` | 整数 | 20 | 1 掃引ステップあたりの J-A 部分積分数 |
| `tand` | `<material_id> <tand>` | 0 | 誘電正接。`frequency` と併用して誘電損 G を求める |
| `debye` | `<material_id> <eps_inf> (<deps> <tau>)...` | なし | Debye 分散材料 (多極可)。`frequency` の値で εr と tanδ に展開する |
| `lorentz` | `<material_id> <eps_inf> (<deps> <f0> <delta>)...` | なし | Lorentz 分散材料 (多極可)。`debye` と混在させると極が足し合わされる |
| `drude` | `<material_id> <eps_inf> (<fp> <gamma>)...` | なし | Drude 媒質 (多極可)。ωp = 2π·fp、Γ = 2π·gamma。低周波では σ = ε0ωp²/Γ の導体になる |
| `colecole` | `<material_id> <eps_inf> (<deps> <tau> <alpha>)...` | なし | Cole-Cole 分散 (多極可)。0 ≤ α < 1、α = 0 は Debye に厳密一致 |
| `anisoeps` | `<material_id> <exx> <eyy> <ezz> [<exy> <eyz> <ezx>]` | 等方性 | 異方性の比誘電率。3 値で対角、6 値で非対角を含む対称テンソル |
| `anisomur` | `<material_id> <mxx> <myy> <mzz> [<mxy> <myz> <mzx>]` | 等方性 | 異方性の比透磁率 (同上)。ν = (μ0μ̃)⁻¹ をテンソルとして逆転する |
| `conductorsigma` | `<conductor_id> <sigma>` | なし | 導体の導電率。DC 直列抵抗 Rs の計算に使う |
| `frequency` | 実数 [Hz] | 0 | 誘電損 (tanδ)・分散材料・渦電流 (`F`) を評価する周波数。0 なら tanδ は無視 |
| `temperature` | 実数 [°C] | 20 | 動作温度。`tempco` / `conductortempco` と併用する |
| `tempco` | `<material_id> <alpha> [<T0>]` | なし | 材料の導電率の温度依存 σ(T) = σ0/(1+α(T−T0))。T0 の既定は 20 °C |
| `conductortempco` | `<conductor_id> <alpha> [<T0>]` | なし | `conductorsigma` で与えた導体に同じモデルを適用する (Rs と `F` が使う系統) |
| `current` | 実数 [A] | 1 | 静磁場解析の励振電流 |
| `analysis` | `C` / `L` / `R` / `M` / `F` / `E` / `A` / `P` の組 | `C` | 実行する解析 (`E` は辺要素の自己検証、`A` は 3 次元渦電流、`P` は節点要素の自己検証。いずれも非構造格子専用) |
| `tline` | `X` / `Y` / `Z` | なし | 伝送線路軸。指定すると単位長あたりの値で出力する (`L`, `M`, `F` は必須) |
| `linelength` | 実数 [m] | 解析領域長 | 等価回路を作るときの線路長 |
| `nsection` | 整数 | 1 | 等価回路 (梯子) の段数 |
| `voltage` | 実数 [V] | 1 | 励振電圧 |
| `awall` | `<physical_tag>` | なし | その面で A の接線成分を 0 にする (B・n = 0)。`analysis = A` 用。複数指定可 |
| `gauge` | `0` / `1` | `0` | `analysis = A` のゲージ固定 (tree-cotree)。R(f)/L(f) はゲージ不変なので既定は 0 (反復が約 6 倍少ない)。A・φ 自体が要るときだけ 1 |
| `frequencysweep` | `<f1> <f2> ...` / `log <fmin> <fmax> <n>` / `lin <fmin> <fmax> <n>` | なし | 周波数掃引。各点で分散材料を展開し直し `ofe_sweep.csv` に 1 行ずつ出す |
| `fieldout` | `0` / `1` | `0` | 解いた場を `ofe_field.vtk` (VTK legacy ASCII) に書く |
| `solver` | `<maxiter> <nout> <converg>` | `10000 100 1e-9` | 反復解法の最大回数・出力間隔・収束判定 (相対残差) |

`shape` は OpenFDTD と共通で、`1`:直方体、`2`:楕円体、`11`/`12`/`13`:X/Y/Z 円柱
(いずれも引数は外接直方体 `xmin xmax ymin ymax zmin zmax`)。

## 制限・未対応

- 実装は CPU (OpenMP) のみ。**CUDA / MPI は未対応** (OpenFDTD にある GPU・
  マルチプロセス版に相当するものは無い)。
- 非構造格子は 3 次元 (四面体) が **C / L / R / E / A / P**、断面 2 次元
  (三角形) が **M / F**。1 つの格子で両方は扱えない。要素は 1 次 (4 節点) と 2 次 (10 節点、等パラメトリック)。
  ただし辺要素の `E` / `A` は 1 次格子専用。3 次以上、六面体・角柱の非構造格子、
  次数の混在は未対応。
- 3 次元渦電流 (`A`) は線形材料のみ。非線形 (B-H) / ヒステリシスとの併用は未対応。
  非導電領域 (空気) は対応済みで検証もあるが、**`awall` の付け方を誤ると
  ソルバーが検出できない**まま答えが変わる (「非導電領域を含む系」節を参照)。
  1 次 Nedelec 要素なので**扁平な要素があると場が一様な方向でも誤差が出る**
  (要素は等方的にとること。ログに最大要素寸法と表皮深さの比を出す)。
- 構造格子では斜め・曲面の導体が階段近似になる (同軸で ~2%)。
  精度が要るときは非構造格子を使う。
- `L` (TEM) は外部インダクタンスのみ。内部インダクタンスと μr が要るときは
  `M` (静磁場) を使う。`M` は 2 次元断面の定式化なので `tline` が要る。
- 表皮効果は `F` (渦電流) で扱う。`Rs` と `M` の L は DC 値 (電流一様) なので、
  高周波では `F` を使うこと。格子が表皮深さを刻めていないと R(f) を
  過小評価するため、その場合は警告を出す。
- 分散材料は **Debye / Lorentz / Drude / Cole-Cole** の多極 (合計最大 8 極、混在可)。
  Drude は準静的な定式化の制約から εr'(ω) > 0 の範囲でのみ使える
  (ω < ωp では εr' < 0 になり ∇・(ε∇φ) = 0 が正定値でなくなるので入力エラーにする)。
  Havriliak-Negami・Cole-Davidson は未対応。
- 異方性は**対称テンソル** (非対角を含む) に対応。非線形との併用は
  軸毎の B-H 曲線 (直交異方性) の形で対応しており、主軸は格子軸に
  一致している必要があります。
- 温度依存は**導電率のみ** σ(T) = σ0/(1+α(T−T0))。σ の読み出し系統が 2 つある
  ので `tempco` / `conductortempco` を使い分ける (「どの解析がどの材料量を読むか」
  節を参照。取り違えると警告が出る)。εr・μr・B-H の温度依存 (キュリー点など)
  は未対応。
- ヒステリシスは**スカラー Jiles-Atherton** (場の向きが回転しない問題向け)。
  ベクトルヒステリシス (回転磁界)、異常渦電流損は未対応。
  非線形/ヒステリシスと渦電流 (`F` / `A`) の同時解析も未対応。
- `M` / `F` は 2 次元断面 (伝送線路) 専用。3 次元の渦電流は `A` (A-φ 定式化、
  非構造格子) で扱う。変位電流を含む全波解析は未対応 (全波は OpenFDTD 側の担当)。

## OpenFDTD との関係

- 入力書式 (`mesh` / `material` / `geometry` の書き方、形状番号)、
  ビルド構成、移植性の規則 (C99 VLA 禁止・`MATH_LIB` 経由の libm リンク等) を
  OpenFDTD に合わせています。`sol/ingeometry.c` の形状定義は OpenFDTD の
  同名ファイルに由来します。
- 一方で解法は独立で、FDTD のコードは共有していません。
