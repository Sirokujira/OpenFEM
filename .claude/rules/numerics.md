# 数値まわりの不変条件

<important if="sol/ 以下を編集するとき">
ここに書かれた不変条件を壊すと、テストが通っても物理的に誤った値を返します。
必ず `sh data/sample/rlc_check.sh` で解析解と突き合わせてください。
</important>

## 行列 (CRS)

- 剛性行列は CRS の 27 点ステンシル。構造格子なので格納位置は `crs_offset()` で
  **探索なしに計算**します。パターンを変えるときは `crs_alloc()` と
  `crs_offset()` を必ず同時に直すこと。
- 剛性行列 (∇w・∇u) と質量行列 (∫σ Ni Nj) は同じ CRS パターンを共有します。
- 要素行列は 2x2x2 Gauss 積分。直方体要素に対して剛性・質量とも厳密です。
- 材料係数は `assemble.c` の `material_coef()` に集約 (mode 0..3)。

## 非構造格子 (四面体)

- `MeshMode` で分岐します。分岐点は `crs_alloc()` / `assemble()` / `setup()` /
  `num_node()` の 4 か所だけ。**それ以外 (Dirichlet マスク、反作用からの
  電荷抽出、反復解法) は格子の種類に依らないので共通のまま**にすること。
- CRS のパターンは四面体の連結から作り、格納位置は二分探索で引きます
  (構造格子の `crs_offset()` は使えません)。
- 1 次四面体は要素内で勾配が一定なので要素行列は厳密。
- `M` / `F` は断面 2 次元の定式化なので非構造格子では入力段で弾きます。

## 辺要素 (Nedelec、`sol/edge.c`)

- 辺は**全体節点番号の小さい方から大きい方**へ向きを揃えます。隣り合う要素が
  同じ辺を同じ向きで参照することがこの規約の全て。局所の並びが逆なら
  要素行列に符号 sgn[k]*sgn[l] を掛けます。**符号を落とすと隣接要素間で
  基底が食い違い、値は出るが物理的に誤った解になります**。
- 質量行列は ∫λ_a λ_b dV = V(1+δ_ab)/20 を使った閉形式で厳密。
  4 つの (1+δ) 因子は対応する勾配内積と組で決まっているので、
  組を入れ替えても対称なままテストを通り得ます (下記の検証を必ず走らせること)。
- 検証 (`analysis = E`) は閉形式で厳密に決まる量だけを見ます。
  (b) 一様場と (c) 回転場 E=½(ẑ×r) は最低次 Nedelec 空間 {a + b×r} に
  含まれるので補間が厳密。**この 2 つを消すと要素行列の誤りが素通りします**。

## 辺要素のゲージと前処理

- ゲージは tree-cotree (全域木の辺で A_e = 0)。木辺の数は必ず
  「節点数 − 連結成分数」。非連結メッシュでも森として動くこと。
- Hiptmair 前処理の節点補助行列 N = GᵀAG は**節点の CRS パターンに必ず入る**
  (同じ四面体の辺の端点は同じ四面体の節点)。入らない寄与があればパターンの
  作り方が誤っている。
- 節点補助系は定数分だけ不定なので 1 点を固定する。
- 節点解を内側 PCG で近似すると前処理が反復毎に変わるので、外側は
  **flexible CG** (β = (r−r_prev)ᵀz / r_prevᵀz_prev) にすること。
  通常の CG のままだと収束が壊れる。
- **誤差は curl (S ノルム) で測る**。回転回転系の悪条件は勾配に近い成分に
  集中するが、その成分は curl A = B に寄与しないので物理量には影響しない。
  生の辺自由度の誤差だけを見ると「解けていない」と誤診する。

## Dirichlet 条件

行列を**書き換えず** `fix[]` マスクで恒等行として扱います (`crs_spmv`)。
解いた後に**元の行列**から反作用 Σ(Kφ) を取って電荷・電流にするので、
行列を破壊してはいけません。

## 静磁場 (`analysis = M`)

- 純 Neumann 系。正味電流が 0 なので可解だが特異なので 1 節点だけ固定して解きます。
- L は相互エネルギー ∫J・A から取るため定数分に依りません。
- **右辺 b は L の計算にそのまま使う**ので、ソルバーに渡すコピー側だけ
  固定節点を 0 にすること。

## 非線形磁性体 (`bh`)

- ν = H(|B|)/|B| を **Gauss 点毎**に評価し、Newton-Raphson で解きます。
  ヤコビアンには rank-1 の補正項 2(dν/dB²)(∇N_i・∇A)(∇N_j・∇A) が要ります。
  残差とヤコビアンで ν の評価点を揃えないと 2 次収束しません。
- **ν の逐次代入 (successive substitution) は使わないこと**。飽和領域で振動して
  発散します (実測: 500 回で残差が 10 倍に発散)。
- 重ね合わせが成り立たないので単一ポートに限ります (入力段で弾く)。
- 軸毎の曲線 (直交異方性) はエネルギーが軸毎に分離するので rank-1 項が出ません。
  等方性 ν(|B|) と直交異方性 H_d(B_d) は別物なので、**同じ曲線を 3 軸に与えても
  等方性と一致しません**。分岐を混ぜないこと。
- 非線形反復の許容値は内側の CG の収束レベルより緩くすること
  (内側が 1e-13 のとき外側の残差は 1e-10 程度で頭打ちになります)。

## ヒステリシス (`ja`)

- 逆 J-A (B が駆動変数)。**H を B/μ0 − M で代数的に求めてはいけない**。
  高透磁率では B/μ0 と M がほぼ相殺し、M の相対誤差 1e-3 が H の 100% 誤差に
  なる。H も B に沿って積分すること (実測: 代数式では H が 100 倍ずれて発散した)。
- ν = H/B は第 2 象限で負になるので**行列に使わない**。行列は微分磁気抵抗率
  dH/dB (常に正) で組み、残差側だけで正確な H(B) を扱う固定点反復にする。
- B は符号付きで持つ (残留磁束・保磁力)。最初に磁化した向きを基準ベクトルとして
  固定し、以降その射影を取る。|B| だけで扱うと反転を検出できない。
- 状態 (B, H, M, 方向) は Gauss 点毎。反復中は Ja*n に書き、収束後に確定させる。
  反復の各回は**確定済みの状態から**積分し直すこと。

## 渦電流 (`analysis = F`)

- 複素対称系 K + jωM を COCG で解きます。内積に**共役を取らない**双一次形式を
  使うこと (共役を取ると収束しません)。
- 境界は自然境界条件 (磁気壁) のままにする。**Dirichlet で切ると帰路電流が
  境界に逃げて Z_loop が壊れます**。
- 基準導体は V'=0 に固定し、ポートのみ励振して Y (np x np) を作り、
  Z_loop = inv(Y) とします。
- 格子が表皮深さを刻めていないと R(f) を過小評価するので、警告を消さないこと。

## 3 次元渦電流 (`analysis = A`、A-φ 連成)

- 未知数は A (辺) と φ (節点)。**節点側の式を jω で割ってから組む**こと。
  そうしないと (1,2) = TG と (2,1) = jωGᵀT が食い違い、複素対称でなくなって
  COCG が使えません。この形なら Kr, Ki とも実対称になり `solver_cocg` を
  ω = 1 でそのまま呼べます。
- Whitney 恒等式から GᵀTG = ∫σ∇N_a・∇N_b なので、**ω→0 で DC の導電解析に
  厳密に帰着**します。これは連成系全体の強い検査になるので必ず見ること
  (実測: 100 Hz で R が DC 抵抗に 7 桁一致)。
- 系は (A, φ) → (A + Gψ, φ − jωψ) で不変なので特異。ただし右辺を Dirichlet の
  持ち上げ b = −A x_D で作れば b は必ず値域に入るので**無矛盾で、COCG は解に
  収束します**。Z はゲージ不変なので既定ではゲージ固定しません
  (実測: 固定すると反復が約 6 倍に増え、Z は 7 桁一致のまま)。
- ゲージを固定しない解の A・φ **そのもの**は物理的な値ではありません
  (A が物理解の 1000 倍、両端 0V/1V の φ が ±60V まで振れる)。場を出力する
  ときは `gauge = 1`。その際は awall の辺を優先して木に入れること
  (でないと A_t = 0 の境界条件と端子電圧が壊れます)。
- **1 次 Nedelec 要素の誤差は要素の最大寸法で決まる**。「場が変化する方向」
  だけ細かくしても足りません。実測: 解が x に一様でも dx = 1.7mm では R が
  13% ずれ (dz は 1/40 まで細かくしても改善せず)、dx = 0.42mm で 1%、
  0.083mm で 0.06%。扁平な要素を作らないこと。
- **表皮深さの診断式に μr を入れ忘れないこと。** δ = sqrt(2/(ω μ0 μr σ)) です。
  ν = (μ0 μ~)^-1 は正しく組んでいるのに診断だけ μ0 で計算していたため、磁性導体で
  δ を √μr 倍に過大評価し、格子分解能の警告が出るべきときに出ませんでした
  (実測: μr = 50, 100 kHz で L が −50% ずれているのに「0.75 × 表皮深さ」と報告)。
  同じ物理を μr = 1・周波数 50 倍で書くと Z は完全に一致するのに警告だけが出る、
  という**内部矛盾**で気づけます。診断の検査には「警告が出るべきケースで出るか」を
  入れること。
- 収束したのに答えが合わないときは、まず**格子の異方性**を疑うこと。
  ゲージ・許容値・格子の 3 つのうち、許容値と z 方向の細分では動かず
  x 方向の細分だけが効いた、という切り分けで原因が分かりました。

## 収束

相対残差で判定。`solver` キーの既定は `10000 100 1e-9`。
非収束は必ずログに `*** NOT converged` を残し、`solve()` の戻り値を非 0 にします。
